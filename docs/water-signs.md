# Reading the river

`src/game/fishing/spotReading.ts` owns water-sign frequency, fish affinity, weight potential, animation settings and learned journal descriptions. Every multiplier stays positive: signs tilt an area's existing pool without guaranteeing a species or introducing fish from another area.

DynamicWorld assigns signs with its persisted RNG. Condition-adjusted fish pools influence the roll; bird activity follows existing wildlife conditions, and false-positive shimmer requires a valid rare habitat/time/weather. Actual rare encounters use the existing condition/pity system and receive broad-shadow or shimmer signs. Their silhouettes are anonymous. Existing nearby/catch audio remains intact.

Calm bubbles favor gentler fish; strong ripples and birds favor better average values; broad shadows favor heavier fish; darting shadows favor stronger bursts. Weight bonuses apply through Cargo's existing quality input. Bird feeding patches last 55 seconds, with the existing off-screen retirement protection. Maps and the minigame are untouched.

Journal details gain a relevant water-reading note after that species is discovered, using existing permanent records. No extra save schema is needed: sign and weighted pool are part of the existing dynamic snapshot. Old snapshots receive a calm (or rare shimmer) fallback without rerolling.

Original native underwater silhouette frames are generated by `node scripts/assets/water-signs.mjs`; bubbles, broken ripples and tiny circling bird wingbeats reuse Phaser pixel graphics.

Verification: `checks/water-signs.html` checks 60,000 catches across all signs, relative reward/weight/pull correlations, twenty varied days, valid terrain, save restoration and journal learning. `checks/signs-view.html` previews each sign at wide/narrow sizes. `checks/rare.html` exercises actual catches, cues, journal, selling and persistence.
