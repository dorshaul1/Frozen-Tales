# Authored exploration network

The original river spine remains fixed. `src/game/world/sideRoutes.ts` owns additional authored branches: Rime Channel, Lantern Hollow, Blueglass Cavern, Underlake Pool, Needle Race and Echo Vault. Caves now have one narrow entrance, an approach passage and an enclosed chamber. Willow Cove, Stillwater Hollow and Needle Race remain open routes; gated branches do not reconnect behind their barriers.

Route definitions contain their centerline, half-widths, interior interval, fishing pool and optional short current jet. The same water contours drive rendering, hull collision, depth, dynamic spawn validation and the River Chart. No trip seed changes these contours.

Cave Cisco, Glassfin Char and Veilfin Burbot use existing fish definitions, fight personalities, specimen weights, cargo slots, values and records. Veilfin uses the existing rare encounter memory and is restricted to Echo Vault. The journal reads these location rules directly. Cave activity is spawned dynamically around the sheltered pockets; no fish has a permanent coordinate. A separate pocket quota avoids crowding the main river or allowing unbounded spot growth.

Personal Lantern lighting adapts to cave darkness, with a small unlit radius and roof occlusion that hides the outside world. Finder, probe and field guide retain their personal-tool actions. Cave drips and ice sounds use AudioManager. Selected thin-ice crossings use the existing Icebreaker module and saved openings. Needle Race contains a short stronger current; Turbo Motor and Current Stabilizer retain their existing effects. Ice Cut, Glacier Sluice, Rime Channel, Blueglass Cavern and Echo Vault have entrance sheets with no rear bypass. Opened state retains the existing persistent IDs. Chamber geometry always permits returning through the opened entrance.

Art recipes: `scripts/assets/exploration.mjs` and `exploration-art.mjs`. Rebuild/validate through the normal asset pipeline. Preview and geometry/spawn checks, including closed/open gate flood-fills using the actual hull and fixed obstacles: `/checks/exploration.html`. Physical sheets: `/checks/traversal.html`. New-fish fight/inventory/record/selling integration: `/checks/cave-fight.html` (isolated test save).

# Village composition

The village keeps its compacted-snow path renderer. `VILLAGE.paths` contains a main waterfront lane and purposeful branches ending clear of NPC bodies. A shore-fast timber repair platform connects the workshop building to the open service slip. `WORKSHOP_BAY` owns its interaction point and three solid decking footprints. The same existing workshop equipment UI and save state are reused.

`workshop-service-dock` and `workshop-parts` are generated by `scripts/assets/village-yard.mjs`. The platform uses native pixels, with a workbench, paddle rack, hoist, fenders, bollards and spare hull; its opening remains unobstructed. Lamps stay beside paths and retain the day/night lighting system.

`/checks/village-composition.html` scans every painted route against walking collisions, provides day/night previews, and walks through all services with actual keyboard input. It uses an isolated save key.
