# Background music

`background.mp3` is an unchanged copy of the audio supplied by the user for use as the game's background music: “WhatsApp Audio 2026-09-09 at 15.17.09.mpeg”. It is a stereo 48 kHz MP3, approximately 56 seconds long. The game decodes it through Phaser and prepares an in-memory seam crossfade; the original file remains intact here.

Short SFX and river/wind ambience are original generated AudioBuffers created by the central Phaser AudioManager. No third-party sound effects are used.
